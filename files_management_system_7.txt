File Management System
-----
2026-08-21
-----
File has been downloaded from a source and is moved to /Downloads, there works script which gives them chmod 400, transliteration on Russian, and add '_' instead ' '. Also, for suspicious files manually works the Clamar antivirus scanner. Useful files receive a tag, useless and one-time go to the trash.

After that the files are moved to /Documents with their tags. In this place they received chmod 600. Secret files are moved to /Documents/protected/. In /protected they are changed their owner to the user Guard with chmod 600, other users cannot open this directory and to do something with the files.

After that the files are moved to /Archive, if they can be useful in the future, or it is required to save it; otherwise, the files go to the trash.
